# 一起学ICAO · 民航英语学习平台

ICAO / OPI 备考练习平台，纯静态单页应用，无外部依赖。

## 功能

- **词汇训练** — 305 条民航专业词汇与词组，卡片速记 + 四选一测验
- **听力复述** — 浏览器 TTS 朗读，0.5~2 倍速可调，先听后看原文
- **OPI 题库** — 318 道问答，5 大章 76 小节，先自答再看高分范例
- **每日学习** — 按星期轮换主题的每日卡片
- 进度自动保存在浏览器 localStorage

## 访问

GitHub Pages: <https://anthony-0629.github.io/yiqixueicao/>

## 本地使用

下载 `index.html` + `data.js` 放同一目录，浏览器直接打开即可（iPad 可用"文件"App 打开）。

## 素材来源

OPI小无相功（个人学习资料整理）+ OPI词组与专业词汇速查表，仅供个人学习使用。
